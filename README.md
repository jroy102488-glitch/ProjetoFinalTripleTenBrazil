# 🔥 Previsão de Risco de Incêndios no Brasil

## Projeto Final — MBA em Ciência de Dados | TripleTen

### Visão Geral

Este projeto tem como objetivo desenvolver uma solução de Machine Learning capaz de prever o nível de risco de incêndio — **Baixo, Médio ou Alto** — para uma determinada região e dia no Brasil.

O projeto utiliza dados públicos brasileiros provenientes da plataforma **Base dos Dados**, integrando informações sobre ocorrências de queimadas, características territoriais e condições meteorológicas.

## Objetivo

Construir uma pipeline completa de Ciência de Dados, desde a análise e preparação dos dados até o desenvolvimento e avaliação de modelos de Machine Learning para classificação do risco de incêndio.

## Fontes de Dados

O projeto utiliza quatro bases principais:

- Banco de Dados de Queimadas — 2024 e 2025
- MapBiomas — estatísticas territoriais e ambientais
- BDMEP — informações das estações meteorológicas
- BDMEP — medições meteorológicas de 2025

## Estrutura do Projeto

- `data/raw/` — dados originais
- `data/processed/` — dados tratados e preparados para modelagem
- `notebooks/` — análises exploratórias e desenvolvimento dos modelos
- `src/` — funções e código reutilizável
- `figures/` — gráficos e visualizações
- `reports/` — relatórios das etapas do projeto
